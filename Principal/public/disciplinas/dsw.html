Desenvolvimento de Software Multiplataforma III || Orientador: Vinicius Heltai Pacheco

A disciplina de Desenvolvimento de Software Multiplataforma III (DSM III) na FATEC é focada na construção de aplicações modernas e distribuídas, integrando o ecossistema Web e Mobile a arquiteturas escaláveis em nuvem.

O objetivo principal é capacitar o estudante a conectar sistemas nativos ou híbridos a APIs robustas, aplicando padrões de projeto avançados e estratégias de entrega contínua.

Principais Pilares da Disciplina

Arquitetura de APIs e Microsserviços: Construção e consumo de serviços Web RESTful e GraphQL, com foco em autenticação (JWT/OAuth2), controle de versão e documentação (Swagger/OpenAPI);

Desenvolvimento Multiplataforma Avançado: Criação de aplicações com código único ou híbrido para Web, Mobile (Android/iOS) e Desktop usando frameworks consolidados (como React Native, Flutter ou Node.js/TypeScript);

Integração e Persistência de Dados: Consumo de banco de dados NoSQL e relacionais na nuvem, manipulação de estados globais na aplicação e sincronização de dados offline-first;

DevOps e Deploy em Nuvem: Introdução à conteinerização de aplicações (Docker), pipelines de integração/entrega contínua (CI/CD) e hospedagem em plataformas de nuvem (AWS, Azure ou Vercel/Render);

Testes e Qualidade de Software: Escrita de testes automatizados unitários e de integração para garantir a estabilidade das aplicações multiplataforma.
